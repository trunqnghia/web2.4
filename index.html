Trực quan hóa thành phần URL bằng CSS

Dưới đây là một URL mẫu đã được phân tách và tô màu làm nổi bật trực quan bằng các thẻ <span> định danh:

https://example.com/products/list?page=2#top

Bảng chú thích mã màu

Thành phần Mã Class Ý nghĩa
Protocol .protocol Giao thức kết nối an toàn (https)
Domain .domain Tên miền định danh của trang web
Path .path Đường dẫn tới thư mục hoặc tệp cụ thể
